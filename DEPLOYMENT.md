# 🚀 Deploy Magno.bp to GitHub Pages

## Quick Deploy (5 minutes)

### Step 1: Push to GitHub

```bash
cd c:\Bloop\Magno.bp
git init
git add .
git commit -m "Deploy Magno.bp mobile game"
git branch -M main
git remote add origin https://github.com/YOURUSERNAME/Magno.bp.git
git push -u origin main
```

### Step 2: Enable GitHub Pages

1. Go to your repository on GitHub
2. Click **Settings** → **Pages**
3. Under "Source":
   - Branch: **main**
   - Folder: **/ (root)**
4. Click **Save**
5. Wait 1-2 minutes

### Step 3: Your Game is Live! 🎮

Your game will be available at:
```
https://YOURUSERNAME.github.io/Magno.bp/
```

## 🔧 Troubleshooting

**Game not loading?**
- Wait 2-3 minutes after enabling Pages
- Clear browser cache
- Check that `.nojekyll` file exists

**README showing instead of game?**
- Make sure `index.html` is in root folder
- Verify `.nojekyll` file is present
- Check GitHub Pages settings
